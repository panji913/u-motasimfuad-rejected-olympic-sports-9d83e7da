One funny single-line sport the Olympics rejected: synchronised eye-rolling, judged like a real broadcast event — four athletes rolling their eyes in perfect unison while their parents explain the Wi-Fi password for the third time. The program writes that single line to `/output/entry.txt`, nothing else.

## Run it

```sh
node main.ts
```

The line is deterministic: every run writes the same 140 characters to `/output/entry.txt`.
